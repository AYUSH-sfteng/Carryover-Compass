# CarryOver Compass

CarryOver Compass is a tool to help AKTU B.Tech students estimate their graduation timeline, predict their promotion status, and plan for carry-over (backlog) paper clearance.

## How to run
1. Ensure Java 17 is installed.
2. Run `./mvnw spring-boot:run` (or `mvn spring-boot:run` if Maven is installed).
3. Open `http://localhost:8080` in your browser.

**Disclaimer:** The rules used in this demo are sample values and are NOT verified. Please confirm all official rules with the AKTU ERP or ordinance.
